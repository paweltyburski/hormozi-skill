claim: Write down the 3-4 assumptions that must be true; pivot if one proves false, push if the conditions hold and you lack skill.
detail: Good failure is learning what to do instead and iterating; bad failure is a false assumption about the world. How long a push takes depends on learning speed and feedback quality.
numbers: 3-4 need-to-believe assumptions.
